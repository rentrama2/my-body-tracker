# BodyFit - แพลตฟอร์มบันทึกน้ำหนักและสัดส่วนร่างกาย (Single File)

แอปพลิเคชันเว็บสำหรับบันทึกและติดตามสัดส่วนร่างกายส่วนตัว (HTML + CSS + JS รวมอยู่ในไฟล์ `index.html` ไฟล์เดียวจบ)

## ฟังก์ชันเด่น
- 📷 **Before & After Photo Slider**: เปรียบเทียบภาพถ่ายรูปร่างแบบเลื่อนซ้าย-ขวา
- ⚡ **Metabolism Calculator**: คำนวณ BMR, TDEE, แคลอรีแนะนำสำหรับลดไขมัน และโปรตีนเป้าหมายอัตโนมัติ
- 📈 **Trends Chart**: กราฟสัดส่วนพร้อมตัวกรองช่วงเวลา (7 วัน, 30 วัน, 3 เดือน, ทั้งหมด)
- 📱 **Mobile Bottom Nav**: แถบเมนูด้านล่าง รองรับการใช้งานบนมือถืออย่างถนัดมือ
- 🏆 **Badges & Milestones**: เหรียญรางวัลความสำเร็จและระบบนับ Streak
- 📊 **Export Excel**: ดาวน์โหลดประวัติเป็นไฟล์ CSV (UTF-8 BOM) เปิดใน Excel ภาษาไทยไม่เพี้ยน
- 🎨 **Shareable Progress Card**: สร้างและดาวน์โหลดการ์ดสรุปผลงานเป็นไฟล์ภาพ PNG
- 🔒 **Privacy First**: ข้อมูลทั้งหมดถูกจัดเก็บไว้ในเครื่องของคุณ 100% ไม่ต้องต่อเน็ต
